# SibKlimat

Единая точка входа находится в корне проекта.

```bash
cp .env.example .env
npm run dev
```

- сайт: `http://localhost:3000`
- Strapi: `http://localhost:1337/admin`

Все команды для разработки и сборки описаны в `DEV.md`. Серверный запуск Strapi и dev-поддомена — в `DEPLOY.md`.

Главная локальная сборка:

```bash
npm run build
```
